Keputusan ini dicatat dalam "log-keputusan.csv" dengan ID K-015. Dampaknya terhadap jumlah baris dan nilai belum dihitung karena komponen yang saya kerjakan merupakan tahap persiapan katalog, bukan implementasi transformasi Silver.

Selain itu, seri "var417" (Harapan Lama Sekolah) tetap diberi status Belum terpetakan karena kode SDG spesifik belum dapat dipastikan dari metadata yang diperiksa. Keputusan tersebut dicatat dalam K-014.

3. Kegagalan dan Pelajaran

Kegagalan yang ditemukan selama pemeriksaan adalah adanya entri duplikat pada "data/raw/MANIFEST.csv", yaitu berkas "sdg4_apk_pt.json" yang tercatat dua kali.

Pada pemeriksaan awal ditemukan 16 entri data manifest, sedangkan jumlah berkas mentah yang tersedia adalah 15. Setelah entri duplikat dihapus, jumlah entri manifest menjadi 15 dan sesuai dengan jumlah berkas mentah.

Pelajaran yang diperoleh adalah pentingnya memeriksa keunikan entri manifest serta mencocokkan ukuran dan SHA-256 setiap berkas sebelum data digunakan dalam proses pengolahan berikutnya.

Memvalidasi seluruh manifest:

python - <<'PY'
import csv, hashlib
from pathlib import Path

root = Path("data/raw")
with open(root / "MANIFEST.csv", encoding="utf-8-sig", newline="") as f:
    rows = list(csv.DictReader(f))

errors = []
for row in rows:
    p = root / row["berkas"]
    if not p.is_file():
        errors.append(f"File tidak ditemukan: {row['berkas']}")
        continue
    if p.stat().st_size != int(row["bait"]):
        errors.append(f"Ukuran tidak cocok: {row['berkas']}")
    if hashlib.sha256(p.read_bytes()).hexdigest() != row["sha256"]:
        errors.append(f"SHA-256 tidak cocok: {row['berkas']}")

files = [p for p in root.rglob("*") if p.is_file() and p.name != "MANIFEST.csv"]
listed = {r["berkas"] for r in rows}
missing = [
    str(p.relative_to(root)).replace("\\", "/")
    for p in files
    if str(p.relative_to(root)).replace("\\", "/") not in listed
]

print("Jumlah entri manifest:", len(rows))
print("Jumlah berkas mentah:", len(files))
print("Berkas belum tercatat:", missing)
print("Kesalahan:", errors)
print("VALID:", len(rows) == len(files) and not missing and not errors)
PY

Hasil validasi terakhir yang diperoleh adalah 15 entri manifest, 15 berkas mentah, tidak ada berkas yang belum tercatat, tidak ada kesalahan ukuran atau SHA-256, dan status VALID bernilai True.
