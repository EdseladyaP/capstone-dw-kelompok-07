## 2. Pengerjaan Tugas 1 — Pembaca Data BPS

## 4. Pengerjaan Tugas 3 — Penggabungan Ekstraksi

Penggabungan seluruh pembaca dilakukan di `src/ekstraksi/__init__.py` melalui fungsi `jalankan()`. Berkas `data/raw/MANIFEST.csv` dipakai sebagai daftar pekerjaan; setiap berkas dicocokkan dengan pola jalurnya, dibaca oleh pembaca yang sesuai, lalu jumlah berkas yang tertangani dibandingkan dengan MANIFEST. Bila ada berkas yang terlewat, proses berhenti dengan galat.

Keluaran pembaca digabung menjadi tabel panjang dengan kolom asli tetap utuh. Pemeriksaan terhadap 15 berkas mentah menunjukkan seluruh SHA-256 sesuai dengan MANIFEST.

Penanganan khusus dilakukan pada Harapan Lama Sekolah (`var417`): berkas memuat provinsi, kabupaten/kota, dan Indonesia sekaligus. Pembaca tetap membawa seluruh 8.732 baris apa adanya; penyaringan dilakukan di Silver berdasarkan kode wilayah (berakhiran `00` untuk provinsi, `9999` untuk Indonesia).

## 6. Reproduksi dan Pengujian Pipeline

Pengujian dilakukan dari klon bersih dengan perintah:

```bash
python unduh_data.py --kasus 7
python pipeline.py
python -m src.common.skema data/silver/silver.parquet
python - <<'EOF'
import pandas as pd
s = pd.read_parquet("data/silver/silver.parquet")
g = pd.read_csv("reports/grid-sel-kosong.csv")
a = pd.read_csv("reports/anomali.csv")
assert len(s) == 4216
assert len(g) == 454 and (g.kategori == "missing").sum() == 3
assert len(a) == 367 and (a.kategori == "outlier").sum() == 262
print("tarik ulang lolos")
EOF
```

Hasil: `data/raw: 15 berkas cocok dengan MANIFEST.csv`, ekstraksi 15 berkas/24.726 baris, Silver 4.216 baris, Gold dan validasi selesai, pemeriksa skema **LOLOS** (4.216 baris, 6 seri), dan seluruh `assert` tarik ulang lolos. Blok lengkap ada di `reports/tim.md` bagian *Cara tarik ulang angka draf ini*.

Bukti hasil individu dicatat di `results/124450095/metrics.json`:
