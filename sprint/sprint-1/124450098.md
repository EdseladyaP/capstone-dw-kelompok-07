# Catatan Sprint 1 – Edsel Adya Pradipta (124450098)

## Peran
- Jalur Komponen: Rekonsiliasi Data dan SQL Silver.
- Tugas Sampingan: Koordinator tim.
- Tugas Sprint 1: Rekonsiliasi seri utama APK Perguruan Tinggi BPS dengan seri pembanding WDI serta perancangan skema SQL Silver, loader, dan validasi data.

## Progres Sprint 1
- Melakukan rekonsiliasi seri utama APK Perguruan Tinggi BPS (`var1443`) dengan seri pembanding WDI `SE.TER.ENRR`.
- Menyusun dokumentasi pasangan rekonsiliasi, periode yang beririsan, dan catatan keterbandingan kedua seri.
- Merancang skema SQL Silver menggunakan DuckDB dengan 11 kolom dan composite primary key.
- Membuat loader Python `src/silver/loader_apk_pt.py` untuk transformasi dan loading data raw ke Silver.
- Melakukan validasi SHA-256 berdasarkan manifest, NULL pada kolom wajib, serta duplikasi primary key.
- Memuat data APK PT BPS sebanyak 393 baris dari 39 wilayah untuk periode 2015–2025.
- Memperbarui `results/124450098/metrics.json` sebagai bukti metrik kontribusi Sprint 1 dan menggabungkannya melalui PR #31.
- Menjalankan koordinasi Sprint 1 sebagai koordinator, termasuk penyusunan Sprint Goal, pemeriksaan Log Sprint anggota, dan persiapan Demo Sprint 1.

## Hasil
- Pasangan rekonsiliasi: APK Perguruan Tinggi BPS (`var1443`) ↔ WDI `SE.TER.ENRR` (nasional).
- Periode irisan kedua seri: 2015–2023 (9 tahun).
- Data Silver berhasil dimuat sebanyak 393 baris dengan 39 wilayah.
- Struktur Silver terdiri dari 11 kolom dengan composite primary key.
- Validasi menunjukkan 0 NULL pada kolom wajib, 0 duplikasi primary key, dan hash berhasil diverifikasi.
- Data yang dimuat mencakup periode 2015–2025.
- Dokumentasi rekonsiliasi, skema Silver, loader, dan metrics telah disiapkan sebagai bukti pekerjaan.
